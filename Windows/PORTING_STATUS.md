## 下一阶段验收顺序

1. **采音实测**：用户指定会议设备后，验证系统声、麦克风和双路同开；静音、戴耳机、扬声器回声、设备拔插和睡眠恢复。当前系统声是所选输出设备混音。
2. **服务联调**：填写用户选定服务，验收连接、首字延迟、手动 / 自动回答、修订取消、纪要分段归并及断网。没有真实 Key 时不能声称已完成此项。
3. **会议稳定性**：30 分钟、2 小时和超长转写；量化丢帧、CPU / 内存、归档一致性与异常退出恢复。当前可读取末尾中断 JSONL；尚未提供完整会话恢复向导。
4. **功能扩展**：先 Codex 后端，再独立 Python / ONNX 的 OCR 与检索服务、ONNX 声纹与翻译；最后手机伴侣和平台特有交互。MLX 与 CoreML 路线需要替换运行后端。
5. **发布工程**：干净机器安装验收、签名安装器、升级回滚、备份导入、ARM64 专项构建。当前为自带运行环境的 x64 ZIP。

## 明确尚未覆盖

当前不包含原 Mac 产品的完整功能：Codex app-server、OCR / 向量检索、说话人声纹、同声翻译、手机伴侣、会议进程发现及进程专属捕获、托盘 / 悬浮窗 / 全局快捷键、订阅授权、自动升级。界面当前按会议通用模式使用问题规则；没有开放全部上游场景预设。

交付目标是可运行、可复现和可继续开发的第一阶段基线；不能作为已经达到 Mac 全功能等价的证明。
