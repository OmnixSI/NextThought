# P4 正式发布准备与长时间验证

基线：Windows 0.3.1，P3 收尾提交 `9e4c65a`。本阶段进行中，不能据此宣称已经正式签名发布。

| 步骤 | 本轮工作 | 状态 |
|---|---|---|
| P4-1 长会议 | 7200 秒公开 PCM 实时双路回放，CPU/内存、队列、最终句延迟、远程请求及归档检查 | 指标预跑通过，准备长测 |
| P4-2 干净机器 | 用户提供另一台 Windows 电脑；交付自带运行环境的安装包、一键自检及结果文件 | 待生成验收包及实机报告 |
| P4-3 安装升级 | 每用户安装、独立版本目录、升级与回退、卸载保留数据 | 用户已选择未签名验收包；尚未实现和验证 |
| P4-4 自动构建 | 源码/版本/依赖/校验和清单、打包及 Windows CI 实际运行 | 待实施，不能把已有 YAML 当作运行成功 |
| P4-5 功能对照 | 按 Mac 功能、数据格式、平台能力列出通过证据及差异 | 待整理；ARM64、BLE 单独保留 |

## 既有约定

- 手机实机命令与重连、USB 插拔继续依用户要求暂跳，热点保持关闭。
- 真实麦克风采音必须先让用户确认，测试弹窗在采音和完成后保持可见。本轮长测先用公开样本，不收集硬件声音。
- 不改变 Mac 签名身份、TCC、Windows 防火墙、代理、驱动或用户游戏配置。
- 未签名包明确标为验收预览；不创建自签名证书冒充可信发布，不将私钥或凭据加入源码、日志和包。
- 自带 .NET 的包不要求目标机器安装 SDK。增强 OCR 仍是可选独立 Python 环境，不能把它计入基础包的零依赖能力。
- 两小时受控回放和第二台机器的真实运行分别记录，不能相互替代。

## 长测指标

`p3-stability-test --label P4 --seconds 7200 --network-attempts 1` 复用已验证链路，增加每 100 ms 观察的 ASR 队列峰值、待处理任务峰值，以及最终句事件投递相对句段结束时间的延迟 p50/p95/max。该延迟包含静音判尾及整句精修，不包含远程翻译等待。

预设通过条件包括完整帧数、零终止性错误、队列不触顶且结束排空、最终句延迟 p95 不超过 5 秒、热身后主进程私有提交增长不超过 256 MiB，以及既有取消恢复、OCR、纪要、导出和备份检查。网络只尝试 1 次，任何失败如实保留。独立 OCR 的内存范围另列，不混入主进程统计。

60 秒预跑：6 条转写、4 次声纹、2 条译文、2 次引用回答，队列峰值 5 帧、结束 0 帧，最终句延迟 p95 约 0.249 秒，取消恢复、纪要、备份通过。证据 `artifacts/p4/pilot.json`。小样本预跑不代替两小时结果。

## 安装器依据

拟使用官方 Inno Setup 7.1.1 x64，固定官方发行 SHA-256 并验证下载工具的 Authenticode；不把编译器加入业务软件运行依赖。基础安装按当前用户运行，数据留在现有用户数据目录，版本目录与数据目录分离。
