## 既有约定

- 手机实机命令与重连、USB 插拔继续依用户要求暂跳，热点保持关闭。
- 真实麦克风采音必须先让用户确认，测试弹窗在采音和完成后保持可见。本轮长测先用公开样本，不收集硬件声音。
- 不改变 Mac 签名身份、TCC、Windows 防火墙、代理、驱动或用户游戏配置。
- 未签名包明确标为验收预览；不创建自签名证书冒充可信发布，不将私钥或凭据加入源码、日志和包。
- 自带 .NET 的包不要求目标机器安装 SDK。增强 OCR 仍是可选独立 Python 环境，不能把它计入基础包的零依赖能力。
- 两小时受控回放和第二台机器的真实运行分别记录，不能相互替代。

## 长测指标

`p3-stability-test --label P4 --seconds 7200 --network-attempts 1` 复用已验证链路，增加每 100 ms 观察的 ASR 队列峰值、待处理任务峰值，以及最终句事件投递相对句段结束时间的延迟 p50/p95/max。该延迟包含静音判尾及整句精修，不包含远程翻译等待。

预设通过条件包括完整帧数、零终止性错误、队列不触顶且结束排空、最终句延迟 p95 不超过 5 秒、热身后主进程私有提交增长不超过 256 MiB，以及既有取消恢复、OCR、纪要、导出和备份检查。网络只尝试 1 次，任何失败如实保留。独立 OCR 的内存范围另列，不混入主进程统计。

60 秒预跑：6 条转写、4 次声纹、2 条译文、2 次引用回答，队列峰值 5 帧、结束 0 帧，最终句延迟 p95 约 0.249 秒，取消恢复、纪要、备份通过。证据 `artifacts/p4/pilot.json`。小样本预跑不代替两小时结果。

## 安装器依据

已使用官方 Inno Setup 7.1.1 x64，下载工具 SHA-256 固定为 `8a5a6711c3766a6e5fb74f280ba0e3551e719ce94538d901fdbd1f8f9920b3f0`，Authenticode 为 Valid、发布者 Pyrsys B.V.；编译器不加入业务软件运行依赖。浏览器下载路径返回 504 后，通过 GitHub 官方发行 API 取得相同哈希的资产；准备脚本保留有界重试和此官方 API 备选路径。

基础安装不提权，位于当前用户 Programs，版本文件与会议/模型数据分离。发布清单核对全部文件路径、大小和 SHA-256，拒绝链接、越界、重复、缺失和清单外文件；未知发布契约拒绝切换。升级和回退不修改用户数据；版本选择原子写入，快捷方式变更在失败时恢复。当前是手动安装升级和显式回退，没有接入自动后台更新。

隔离生命周期使用独立 QA AppId、开始菜单/桌面快捷方式和中文含空格目录；旧版桌面文件是原 0.3.1，单独 tools 目录附上新部署助手用于建立旧版安装基线。该 QA 包不是重新发布的 0.3.1。通过 20 项检查：首次安装、故障拒绝、旧状态/快捷方式/注册版本保留、升级、损坏旧版拒绝回退、正常回退、再升级、卸载及合成会议/模型/凭据标记字节不变。未改动真实用户数据或原发布 ZIP。

首轮失败：Inno 文件回调抛出异常在静默模式下可能被记录后继续安装，导致故障候选仍被激活。已取消依赖异常传播，改为显式校验/激活门控、事务式快捷方式和非零退出码；第二轮故障不再激活。首轮证据 `artifacts/p4/installer-qa/lifecycle.json` 保留，修复通过证据为 `lifecycle-fixed-v2.json` 及同目录日志。失败候选可留在版本暂存目录，但未被选作启动版本；后续成功升级和卸载均已验证。

签名脚本只接受当前用户已有的代码签名证书与 Windows SDK SignTool，SHA-256 签名和时间戳后验证发布者；签名分支没有真实证书，尚未端到端验收。缺失身份时拒绝签名，不生成或替换证书、不回退冒充签名。用户已明确选择先交付未签名验收包。

## 自包含运行与自动构建准备

79 项自动回归全部通过、0 跳过，Release 构建 0 警告、0 错误。新增回归覆盖升级/回退保持数据、损坏拒绝、越界及清单外文件、切换前壳层失败和未来发布契约。桌面追加内部启动自检，不模拟鼠标键盘、不激活屏幕，不采集声音；常规窗口和自检窗口都由应用显式构造。

本机自包含隔离检查通过：将已发布文件复制至中文含空格路径，子进程 PATH 只保留 System32，DOTNET_ROOT / DOTNET_ROOT_X64 指向不存在的目录、禁用多级查找；CLI 发布校验、原生库、中文合成备份通过，WPF 实际加载并完成首帧、就绪且未录音，显示版本 0.4.0，约 0.58 秒。空隔离数据目录没有语音模型，因此该项没有执行 WAV 推理；本机实际模型的公开 WAV 推理另有 doctor-local.json 通过。证据 `artifacts/p4/release-smoke-v2/smoke.json`。这不是新的干净 OS 或交互布局验收。

首版内部启动自检曾将 WPF StartupUri 赋空，触发 ArgumentNullException；已改为显式创建窗口。失败证据 `release-smoke-v1/smoke.json` 保留，修复后的实际 WPF 检查通过。

Windows CI 已准备固定的 windows-2025、只读内容权限和官方 Actions 的提交 SHA，执行锁定 SDK/依赖、回归、便携包、未签名安装器及自包含/WPF 冒烟，并保存版本、源码提交、逐文件哈希及校验信息。此时尚未上传验收分支或取得远程运行结果，不能将本机脚本通过计作远程 CI 通过。
