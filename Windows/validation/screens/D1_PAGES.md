# D1 页面截图清单

一条命令：`NextThought.exe --demo --screenshots=<dir>`。截图会生成中/英 × 浅/深全量，再按视图复制到本目录。本轮全量批次共 96 张 PNG。

| D1 页面 | Windows 证据 | Mac 对照 |
|---|---|---|
| 首页 | `home/light.png`、`home/dark.png`、`compare-home-light.png` | `docs/screenshots/v3/home.png` |
| 准备 | `prepare/prepare-light.png` | 无 mac 脚本副页；Mac PrepareView.swift |
| 会中 | `live/light.png` | `docs/screenshots/v3/live.png` |
| 会中纪要 | `notes/notes-light.png` | `docs/screenshots/v3/notes.png` |
| 回顾 | `notes/review-light.png` | Mac NotesPageView 回顾 |
| 工作纪要 | `notes/work-light.png` | Mac NotesPageView 工作纪要 |
| 资料库 | `library/light.png`、`compare-library-light.png` | `docs/screenshots/materials-light.png` |
| 设置 | `settings/light.png`、`compare-settings-light.png` | `docs/screenshots/settings-simple-light.png` |
| 设置的纪要页 | `settings-pages/settings-notes-light.png` | Mac SettingsPage 纪要 |
| 提词岛 | `island/island-*.png`（7 态） | `docs/screenshots/island-*.png` |

差异：演示会议标题已接近 Mac，但转写、回答、纪要正文不是 Mac 截图逐字文本；页面布局差异见 `DIFFERENCES.md`。因此 D1 保持「已实现、未验证」，不能标「已验证」。
