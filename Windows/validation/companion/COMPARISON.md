# F12 手机伴侣范围与生命周期对照

| 项目 | Mac 做法 | Windows 做法 | 是否一致 |
|---|---|---|---|
| 监听地址 | RFC 1918 私网 + 回环 | RFC 1918 私网 + 回环；已移除 100.64.0.0/10 | 一致 |
| 端口 | 随机端口 | 随机端口（`port: 0`） | 一致 |
| 令牌传递 | 配对链接 fragment 内 base64 JSON 的 token；请求 query `t` | 同左（`#p=` base64url，`?t=`） | 一致 |
| Host 校验 | 只接受配对 authority | `Host` 必须等于 `BaseUri.Authority` | 一致 |
| 生命周期 | 跟随 App 运行，用户关闭伴侣即停止 | 跟随 App 运行，用户关闭或退出即停止（已去掉 8 小时自动停止） | 一致 |
| 连接上限 | 有限连接数 | 24 个连接、8 个事件流 | 一致 |
| 动作应答 | 立即应答、幂等 | 立即 204、命令 id 幂等 | 一致 |
| 中继 | 中转通道 | `CompanionRelayClient` 已有 | 需与 Mac 配对参数核对 |

结论：地址范围、令牌传递、Host 校验和生命周期已按 Mac 行为收紧；中继配对参数仍需 Mac 端确认。
