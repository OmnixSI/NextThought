# NextThought 0.4.0：第二台 Windows 电脑验收

此包是按用户选择制作的**未签名验收预览**，用于 Windows 10 build 19041+ / Windows 11 的 x64 电脑。ARM64 不在本包验收范围。无需安装 .NET SDK、Visual Studio、Office、Codex 或 Python 即可运行基础软件；增强 OCR 是另外准备的可选 Python 组件。

## 安装和第一次运行

1. 将整个验收 ZIP 复制到第二台电脑，完整解压。
2. 双击 `NextThought-Windows-preview-0.4.0-setup-unsigned.exe`。默认按当前用户安装，不需要管理员权限。
3. 完成后从开始菜单的 **NextThought Windows Preview → NextThought** 启动。
4. 程序默认位于 `%LOCALAPPDATA%\Programs\NextThought`；会议、设置及模型位于 `%LOCALAPPDATA%\NextThought`。二者分开，不要把安装目录选成数据目录。

没有可信代码签名证书，因此此包不能当作已签名正式版。若系统阻止运行，请记录提示反馈，不要关闭安全软件或修改安全策略。

## 分两次运行自检

**第一次：基础运行环境。** 开始菜单选择 **一键自检**。它检查发布文件哈希、系统与架构、UTF-8、原生识别库、音频设备枚举、系统 OCR、中文路径和合成备份。没有模型时，基础自检可通过，但公开 WAV 推理会明确显示“未执行”。

**第二次：模型准备与本机推理。** 在软件“设置”中准备推荐的 **480 ms 流式语音组件和整句精修组件**，等待下载、校验完成；随后再运行 **一键自检**。最终应看到：

- 基础自检：通过。
- 语音模型就绪：True。
- 公开 WAV 推理：True。

公开 WAV 是随包提供的约 10 秒测试音频，自检不采集麦克风或系统声音，不请求 DeepSeek/Codex，不需要 API Key，也不读取实际会议内容。模型下载需联网；下载失败请保留具体提示，不要把已有模型的本机结果当作第二台电脑下载通过。

报告位于当前 Windows **桌面 → NextThought-验证结果**：`doctor.json` 和 `doctor.md`。运行窗口会显示实际位置。把**第二次的这两个文件**带回开发电脑供核验；也可先反馈基础自检、模型就绪、WAV 推理三项结果及具体错误。

报告只记录系统/架构、检查状态、模型就绪和公开样本结果；不含 API Key、设备 ID 或真实转写。它会区分中文文件夹路径与实际 Windows 用户目录是否包含非 ASCII 字符，不自动把中文文件夹测试当作中文用户名实测。

## 升级、回退和卸载

- 同一安装器身份的新版本继续安装到原程序目录。不同版本位于 `versions\<版本号>`，保留上一版供显式回退。
- 升级前先结束会议、关闭 NextThought，并从软件导出 `.ntbackup` 保留数据副本。
- 开始菜单 **回退上一版** 会先校验上一版文件，再切换启动快捷方式。没有上一版或校验失败时拒绝回退，当前版本保持。
- 通过 Windows“已安装的应用”卸载程序。卸载不删除外部会议、模型和设置目录；不要手动删除 `%LOCALAPPDATA%\NextThought`。
- 当前没有应用内后台自动更新，也不执行跨归档模式的自动数据迁移。Mac 双向实机兼容、BLE、ARM64 和连续长时硬件采音仍是独立专项。
