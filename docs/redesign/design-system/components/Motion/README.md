# Motion

动效的原则是：**安静、短、有目的**。高级感来自克制，不来自花样。

| 场景 | 时长 | 曲线 | 做法 |
|---|---|---|---|
| 悬停、按下 | 120ms | `cubic-bezier(.2,.8,.2,1)` | 底色变化；按下缩到 0.98 |
| 展开、切换 | 200ms | 同上 | 只做透明度和高度，不做位移 |
| 阶段转场（准备 → 进行中 → 纪要） | 320ms | 同上 | 内容交叉淡入；“开始”按钮原地变成录制计时 |
| 流式回答 | 每词 160ms | 同上 | 逐词淡入，不位移 |
| 电平 | 每秒 8 次 | 线性插值 | 平滑，不闪 |

**不用的效果：** 弹簧回弹、放大弹出、整块滑入、彩色渐变流光、循环呼吸灯（录制红点除外，而且红点也是静态光晕）。

开启“减少动态效果”后，所有淡入都改成直接出现。
