# 会后 · 工作会议纪要 · Notes (work meeting)

模板“工作会议”的样子。

- **待办写成表**：做什么 · 谁 · 哪天交付。“周二”“周四”这类说法会换算成具体日期，以会议日期为准。
- **每一条都引用原话时间点**，例如 `[05:40]`，点击跳回转写。
- **说法不一致或听不清的地方标“待确认”**，例如设计稿复审到底是周四还是周五。
- **“风险和未决问题”是这个模板里的“不足”部分**：没人认领的事、没说清楚的事。
- 头部可以换模板；标题下面写着“已校对 4 处识别错误”，点开能看到改了哪里。
- 线上会议的“对方”是会议软件里所有人的声音，所以待办只能归到“我 / 对方”，或者原话里点了名的人。
