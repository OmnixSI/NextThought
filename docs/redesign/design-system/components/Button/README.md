# Button

主按钮用**墨色**（浅色主题是近黑底白字，深色主题反过来）。品牌紫不用在按钮上，因为紫色只代表 AI。

## 什么时候用
- **大主按钮**（40px）：一页里最关键的那一步，比如“开始”“准备这场会议”。每页最多一个。
- **主按钮**（32px）：一个区域里最主要的动作，比如“发送到飞书”。
- **次按钮**（`sunken` 底）：其他动作。同一行最多 3 个，其余收进“…”。
- **无底按钮**：低调的动作（复制、更简短），悬停才出现底色。

## 状态
- 悬停：主按钮透明度降到 0.88，次按钮换成 `hover` 底。
- 按下：缩小到 0.98，120ms。
- 焦点：2px `focus` 描边。

## 文字
2–4 个字的动词。快捷键用浅色写在按钮里，比如“立即记录 ⌘⇧N”。
