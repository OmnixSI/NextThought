# 会中 · 提词 · Live (Prompt)

开始后，窗口进入**专注模式**：侧边栏、首页、资料夹、设置全部收起，只剩这场对话。上方浮着的是提词器，放在摄像头下方。

**顶栏**（从左到右）：
- 录制计时：点一下暂停。
- 会议标题。
- **提词 / 只记录**：会中随时切换，代替原来的“自动回答”开关。
- **手机**：只有开启了手机伴侣才出现。绿点表示已连接，琥珀点表示正在重连；悬停显示“已连接 1 台手机 · 局域网”。
- **模型标签**：`gpt-5.5`，开着快速模式时后面有 ⚡。点开是“回答设置”（见 AnswerSettings）。
- 提词器开关、**结束**。

**右栏 · 建议回答**：
- 联网状态只在发生时出现：“正在联网核查…”，查完变成“联网版 · 3 个来源 · 看原回答”，来源用上标数字标注。
- 下方露 3 个改写，其余和“重新生成”“联网查一下”在“…”里。
- 头部 ‹ 2/5 › 翻看本场的回答记录；底部一行写着依据。

**底部**：输入框（⌘L 聚焦）、截图图标（框选区域 / 选择窗口），以及全窗口唯一的主按钮 **立即回答 ⌘⇧↩**。
