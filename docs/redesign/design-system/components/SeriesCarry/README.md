# SeriesCarry · 接着上一场

准备页第 2 步，**只在找到同一系列的上一场时出现**。

- 第一行写清“这是「字节跳动 · 后端」的第 2 场 · 上一场 10 月 22 日”。认错了可以点“不是同一个系列”。
- 可以带入的东西列成勾选框，每行右侧写数量：
  - 资料：默认勾上。
  - 上一场复盘：默认勾上，附带“待改进”的题数。
  - 经验：默认勾上。
  - 完整转写：太长，默认不勾。
- 没自动认出来时，用资料旁边的“从以前的会议带入…”手动选。

实现上，系列就是现有的“场景”（`Workspace`），它已经存着资料、`lessons` 和 `questionBank`；会话记录通过 `workspaceID` 关联到它。
