# 本机模型发现与复用验证

日期：2026-10-21。实际机器：Apple M2 Pro / 16 GB / macOS 26.5.2。macOS 14 是兼容目标，不是本次真机测试系统。

## 原因与修复范围

原有真实文档测试使用显式模型目录和隔离运行包，正式 App 按自己的应用数据目录判断安装。另发现启动时共享安装版本计数导致语音刷新使慢文档校验过期，并永久停留在“正在检查”；本次拆分语音与文档安装计数。测试文件存在，不代表正式 App 已接入。本次在本机校验并接入保留的三套固定权重与已发布运行包，没有重新下载模型，没有改变语音模型或 OCR／语义检索选择。

代码新增手动扫描和目录选择；准备文档组件之前也先找本机有效资产。只支持固定清单中兼容的 Paddle Q8、版面、Qwen Q8 和运行包；文件名相同、原精度权重或其他 revision 不会直接被判定可用。权限、索引和扫描预算限制会提示，不能保证读到所有未授权目录或未索引磁盘。

## 验证

- 148 项 Swift 测试通过，包含隐藏缓存、HF 文件符号链接、只有配置文件的固定 revision、不完整快照、同大小错误内容、损坏目标修复、原件保留、重复复用、索引中的外部路径、目录预算和取消。
- 隔离 `local-models` 集成自检：从显式目录复用 1,879,748,410 字节固定资产，三套模型逐文件校验，运行包通过归档／签名／重定位与 NDJSON 健康检查；重复执行不再次导入，无网络下载。
- 正式安装路径真实 Embedding：1024 维，相关文本相似度 0.76810753，无关文本 0.08859579；此为路径可用性样例，不是总体准确率。
- 正式安装路径 Paddle 严格模式重新处理合并表格样例：46.4 秒，保留 `colspan="2"` 与 1,234.56、1,789.01、987.65、1,012.34、2,222.21、2,801.35。未使用系统 OCR 回退。
- 真实权重启动回归 `model-readiness`：文档 SHA-256 校验期间同时递增语音安装版本，仍正常标记三项模型就绪；1.9 秒通过。
- 隔离 `.ci` bundle 的 `document-setup` 自检通过；禁止在正式 bundle 中运行会写设置的该项自检。
- Release build 通过；保留原有 WorkspaceStore 的 Sendable 警告，没有新增模型扫描编译警告。
- 既有 CodexTransport 离线回归与 4 项文档 Python 测试通过。

- 本机修复版安装到原应用位置，沿用同一签名 designated requirement；原 OCR 选择仍为系统、原语义开关保留。真实界面显示 3/3 模型与运行包已安装，扫描按钮完成且无下载；现有资料形成 16 个片段向量。
- 验证结束再次核对全部 26 个固定资产 SHA-256；删除测试导入副本、临时 App 与本轮构建缓存，保留生产权重、运行包及压缩日志。当前为本机修复版，尚未发布新正式版本。

原始运行日志和本机安装核对保存在忽略目录，不提交用户资料、模型权重或运行包到 Git。
