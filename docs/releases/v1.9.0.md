# InterviewHacker v1.9.0

会前资料改用持久任务队列：可连续导入，逐文件显示真实解析／OCR／索引进度，支持取消、重试与检查点。单文件范围提高至 512 MiB、PDF 2000 页；旧 `.ppt` 可通过本机 LibreOffice 转换。资料完成后独立可用，会中暂停重型准备并保留就绪版本。大容量填充 PDF 测试只证明容量，不代表同等规模扫描件的 OCR 准确度。

手机网页统一问题、答案及状态，修复切题错配，增加 SSE 失效检测、快照补拉和命令去重。可自建端到端加密 WSS 中转；另提供 Android／iOS 原生伴侣源码与 BLE 备用协议。Android 调试 APK 可供评审；iOS 安装版尚未提供。蓝牙、相机及两种实体手机各 60 分钟使用尚未完成实机验收。

屏幕可选窗口、显示器或区域，系统 OCR 提供快速上下文，本机增强针对变化区域；每次回答冻结画面及来源。检索允许无相关资料，通用知识不被无关片段限制；联网修订由用户手动应用，不突然替换正在朗读的答案。每题依据和降级原因随会话归档保存。

自动备份改为会议结束和重要变更前触发，通过内容哈希复用文件；导入先检查路径、容量和原文件完整性。新增权限故障回归：目录不可读时明确失败并保留旧恢复点，避免不完整快照被当作成功。

Astra 审查后改善会前异常摘要、依据限制、手机配对、历史位置、操作回执、停止生成入口及应用图标。包含本机已有 OCR／Embedding 组件发现与复用修复，沿用固定文档运行包，无需重新下载有效模型。

本地验证：172 项桌面 Swift、3 项共享手机 Swift、3 项 Android JVM、Android 15 ARM64 模拟器实际 TCP／Compose、3 项 Node WebSocket、网页恢复与操作回执、7 项 Python 文档及隔离应用备份／Vision／MCP 检查通过。独立质量评测仍待完成；100 题搜索路由召回 96%、稳定题误触发 0%，其中 52 题模型判断超时后回退规则，不代表模型延迟已达标。

本次在用户明确接受剩余实机与质量验证限制后推进合并与发行，不能解读为全部验收通过。详见 [验收及恢复说明](https://github.com/OmnixSI/InterviewHacker/blob/v1.9.0/docs/STABILITY-REVIEW.md)。Apple Silicon / macOS 14+ 为目标，发行包的具体构建／签名结果以资产校验记录为准；未提供 Developer ID 公证。升级前结束辅助会话并保留一份手动备份，原有资料、模型和旧备份继续兼容。
