## InterviewHacker v1.4.0

### 亮点
- **新手引导**：第一次打开时按步骤完成：系统权限 → 下载识别模型 → 连接回答引擎（可一键「测试回答」）→ 建第一个场景 → 使用前检查。可以跳过，之后在 设置 → 基础 重新打开。
- **设置更简洁**：分为 基础 / 识别 / 回答 / 提词器 / 数据 / 更多 六组。「基础」页是使用前检查，逐项显示权限、识别模型、回答引擎、当前场景、本机签名的状态，缺哪项点哪项补上；不常用的选项收进各页的「高级选项」。
- **Codex Fast 模式**：与 Codex 客户端里的 Fast 相同（约 1.5 倍速度，消耗更多套餐用量）。在 设置 → 回答 或输入框旁的 **Fast** 按钮切换，下一次回答生效。哪些模型支持、速度说明都读取 Codex 的模型列表；默认就是 Fast 的模型（如 gpt-6-luna）可以关掉，改用标准速度。
- **窗口比例**：主窗口每次打开都恢复为 1120×820（屏幕较小时自动缩小）并居中，最小 960×660，不再出现竖长窗口里元素挤在一起、标签文字竖排的情况。菜单「窗口 → 恢复最佳窗口大小」（⌥⌘0）。

### 升级说明
- 已有的场景、记录和设置都保留；升级后会显示一次新手引导，可以直接跳过。
- Fast 模式需要用 ChatGPT 账号登录 Codex，并使用较新版本的 Codex。

### 安装
下载 `InterviewHacker-1.4.0-macOS-arm64.dmg`，拖进“应用程序”。应用未经公证，首次打开时到 系统设置 → 隐私与安全性 点“仍要打开”。需要 Apple Silicon 与 macOS 14+。已经装了 1.3 的用户，在应用内更新即可。
