## InterviewHacker v1.5.0

### 亮点
- **联网搜索**：先马上给出快速回答。问到价格、新闻、版本、现任人员、“今天 / 最近”、今年的事等需要最新信息的问题时，在后台联网，查好后自动换成联网版，随时可以切回原回答；任何回答都可以点“联网查一下”。可选关闭 / 自动判断 / 每次都查。搜索方式：Codex 实时搜索（ChatGPT 账号），或 Tavily（填 Key，回答标注 [1] [2] 来源）。
- **助手页模块可拆可合**：实时对话、当前问题与候选、建议回答、回答记录可以拖动换位置、拖动空隙调整大小、隐藏；把模块拖出窗口就变成独立小窗，拖回主窗口（或关闭小窗）就合并。“布局”按钮里有预设布局，布局会被记住。新增“回答记录”模块，点一下回看之前的回答。
- **回答更像人说的话**：按“照着说出口”来写，第一人称、短句、自然衔接，不再是提纲和 AI 套话；回答知道今天的日期。
- **API 预设**：保存多家服务商（地址、Key、模型、思考强度），一键切换，可从服务商获取模型列表。
- **技能**：导入自己的 SKILL.md / Markdown，“所有场景”启用或按场景勾选。
- **判断模型（JEV）接口**：可选。本地规则拿不准“是不是在问我”“要不要联网”时交给快速模型判断，1.5 秒没结果就按规则处理。接口约定见仓库 docs/JUDGE-API.md。
- **麦克风**：修复你说的话被误当成扬声器回声丢掉的问题；疑似回声改为灰色显示，点“是我说的”恢复；麦克风未开启或未授权时有提示。

### 升级说明
- 原来的 API 配置会自动变成第一个预设；场景、记录和设置都保留。
- 联网搜索默认是“自动判断”，搜索方式默认 Codex；没有登录 Codex 又没填 Tavily Key 时不会联网，其他功能照常。
- 助手页默认新增“回答记录”模块（在对话下方），不需要可以在“布局”里隐藏。

### 安装
已经装了 1.4.x 的话，在应用内更新即可。新安装请下载 `InterviewHacker-1.5.0-macOS-arm64.dmg`，拖进“应用程序”；应用未经公证，首次打开时到 系统设置 → 隐私与安全性 点“仍要打开”。需要 Apple Silicon 与 macOS 14+。
