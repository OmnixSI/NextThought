## InterviewHacker 0.2.0 beta 3 · 液态玻璃界面

界面整体按 Apple 液态玻璃（Liquid Glass）风格重新设计：

- 🫧 macOS 26 上使用系统液态玻璃材质（折射、高光、按压回弹）；macOS 14–15 使用磨砂玻璃效果。
- 🪟 主窗口半透明，顶部悬浮玻璃标签栏，底部悬浮玻璃输入栏（提问 / 截图 / 立即回答）。
- ✨ 新的会话主卡片与聆听动画，开始辅助时按钮内显示加载进度。
- 🪄 回答、候选问题、转录、设置、资料全部改为玻璃卡片；提词器为玻璃浮窗。
- 🌗 外观默认跟随系统。

同时包含 beta 2 的修复：手机伴侣端口自动切换、摘戴耳机不再中断辅助、开始辅助大幅提速。

### 安装

下载 **`InterviewHacker-0.2.0-beta.3-macOS-arm64.dmg`**，拖进“应用程序”替换旧版。首次打开如被拦截，到 **系统设置 → 隐私与安全性** 点 **“仍要打开”**；升级后如录屏或麦克风权限失效，在“隐私与安全性”里把 InterviewHacker 关掉再打开一次。
