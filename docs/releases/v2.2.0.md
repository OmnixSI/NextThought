# Interview Hacker v2.2.0

本版本重做首次引导，新增不依赖 Codex 的 API 接入，并加入一批让会议更省心的功能。

- **新的引导**：六步，带内置示例会议（不需要权限，也不调用模型）；麦克风权限只在点“开始记录”时才询问。
- **不装 Codex 也能用**：选服务商（DeepSeek、通义千问、Moonshot、智谱、火山方舟、OpenAI、OpenRouter、Groq、Ollama、LM Studio）、粘贴 Key、点“保存并检查”；失败时说明是 Key、地址还是网络的问题。没有 Codex 时默认使用 API，已选择 Codex 的用户保持不变。
- **会议自动收尾**：长时间没人说话时提示并倒计时，自动结束并整理纪要；可只提示或关闭。
- **字幕条**：实时窗口可收成屏幕底部的字幕条，不抢焦点，⌃⌥S 切换完整窗口 / 字幕条 / 隐藏。
- **术语与人名表**：记录术语、人名和常听错的写法，用于识别提示、回答和纪要纠错。
- **更多纪要格式**：提纲（上课）、鱼骨图（组会）、观点对照表（讨论），要点标注出处；仍可只用文字纪要。
- **区分说话人（实验，默认关闭）**：本机声纹模型在会议内区分对方的每个人；可录入“我的声音”，之后自动把你的发言标为“我”。声纹只存在本机，不上传，可随时删除。

需要 Apple Silicon 和 macOS 14 或更新版本。
