# NextThought v3.1.0

为双屏演讲做的一版：外接屏共享幻灯片，MacBook 放演讲者视图和 NextThought，提词岛一直展开在摄像头下方。

## 双屏演讲

- 在齿轮面板、会中菜单或“全部设置 → 提词与教练”里打开“双屏演讲”。接着外接屏时，它会说明幻灯片在哪块屏幕上。
- 会议开始后，提词岛在 MacBook 摄像头下方一直展开，主窗口让开，不挡 PowerPoint 或 Keynote 的演讲者视图；需要时用 ⌃⌥S 叫回主窗口。
- NextThought 读取幻灯片所在的屏幕，跟着你翻页：提词岛显示“第几页 / 共几页”、这一页的要点（讲过的变灰，下一句高亮）和到下一页的过渡。被提问时，回答优先显示，讲完后回到幻灯片要点。要跟随幻灯片，先把这份幻灯片（PPT、Keynote 或 PDF）放进这个系列的资料。
- 外接屏上不会出现 NextThought 的任何窗口。会议中途插拔外接屏，双屏演讲会自动开启或关闭；只有一块屏幕时不会把主窗口藏起来。
- 演讲时临场教练不再提示“说得太久”和“该听对方说了”，只保留语速和眼神。
- 会议结束后，屏幕读取和窗口恢复到会前的设置。

## 提词岛一直展开

- 新开关“提词岛一直展开”：会中不用把鼠标移上去，最新的回答一直完整显示，不再自动收起。齿轮面板、会中菜单、设置页都能开关，快捷键 ⌘⇧E，提词岛上也有一枚图钉。
- 一直展开时点提词岛顶部一行，可以在回答和会议面板（立即回答、暂停、结束）之间切换。

## 修复

- “会议记录未能完整读取 · 缺少 meta.json”反复出现：旧版本在会议删除后写下的纪要文件会留下一个只有 `notes.json` 的文件夹，被当成损坏的会议。现在这类不含任何录音内容的文件夹会移到数据目录的 `Previous Data/Leftover meeting files` 里保存，不再提示；仍有转写等内容的文件夹照旧提示，交给你处理。

## 尚未实测

双屏演讲跟随幻灯片、实际屏幕共享和真实音频下的整场会议，还没有在真实演讲中验证过。
