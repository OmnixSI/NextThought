## InterviewHacker v1.6.0

### 亮点
- **屏幕感知**：可选地每隔几秒在本机识别屏幕文字（排除 InterviewHacker 自己的窗口）；只有屏幕内容与最近对话相关时才纳入回答。
- **讲稿跟随**：播放导入的 PPT、Keynote 或 PDF 时识别当前页，整理本页要点、过渡句和听众可能提出的问题；讲过的要点会自动标记。
- **回答进度**：边听边标记已经讲到的讲稿内容，并提示下一句。
- **屏幕与讲稿模块**：可在助手页的模块菜单中显示或隐藏。
- **助手页布局更简单**：通过模块菜单选择预设、显示或隐藏模块；调整分隔条时界面更稳定。
- **问题判断使用本地规则**：移除可选的 JEV 判断模型；问题识别、联网搜索判断和回声判断由本地规则处理。

### 升级说明
- 现有场景、会话记录和设置会保留。
- 屏幕感知为可选功能；首次使用时按 macOS 提示授予录屏权限。

### 安装
已经装了 1.5.x 的话，可以在应用内更新。新安装请下载 `InterviewHacker-1.6.0-macOS-arm64.dmg`，拖进“应用程序”；应用未经 Apple 公证，首次打开时到 系统设置 → 隐私与安全性 点“仍要打开”。需要 Apple Silicon 与 macOS 14+。
