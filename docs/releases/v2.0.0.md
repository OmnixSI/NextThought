# InterviewHacker v2.0.0

全新界面与交互：“纸与墨”视觉语言，每场会议就是一页。完整设计见 [docs/redesign](https://github.com/OmnixSI/InterviewHacker/blob/v2.0.0/docs/redesign/README.md)。

**一场会议 = 一页。** 首页直接显示接下来要做的事。新会议先进入准备页，四步完成：
1. 会议类型
2. 接着上一场
3. 这次新加的资料
4. 开始前检查：声音、回答模型、手机

点“开始”后窗口进入专注模式，只保留这场对话；结束后同一页变成纪要。不想准备时，用“立即记录”直接开始。

**会议类型与系列。** 共有 8 种类型：通用、面试、汇报 / 答辩、组会、工作会议、客户沟通、讲座 / 课程、小组讨论，另外支持自定义。类型决定会中是“提词”还是“只记录”、回答长度和纪要模板。同一件事的多场会议归为一个系列，比如一面、二面。二面准备时，可以勾选带入一面的资料、复盘和经验。原来的“场景”就是系列，旧数据直接沿用。

**会中只留这场对话。**
- 侧边栏、首页和设置都收起。
- 顶栏只有这几样：计时（点一下暂停）、提词 / 只记录切换、手机连接状态、当前模型、提词器开关、结束。
- 模型、快速模式、联网、回答长度集中在模型标签打开的“回答设置”里。
- 回答下方只露 3 个改写，其余收进“…”。
- “立即回答”是唯一的主按钮。

**声音不再依赖识别会议软件。** 线上会议默认听这台 Mac 播放的所有声音，再加上麦克风，任何会议软件都能用。线下会议只用麦克风，转写标为“现场”。音频仍然只在本机识别，不保存。

**会后纪要单独整理。** 纪要使用单独设置的模型，分三步：
1. 校对转写：AI 按上下文和资料里的专有名词纠正识别错误，改过的地方有标记，可以撤销。
2. 按场景模板整理。
3. 核对：每条都引用原话时间点，相对日期会换算成具体日期，不确定的标“待确认”。

内置 7 个模板，包括面试复盘、学术、工作会议、客户沟通、讲座、小组讨论和通用，也可以自定义。每个模板都有“不足”这一部分。面试复盘可以一键存进题库。

**中英文。** 可以在“设置 → 语言”里切换界面语言，切换后 App 会重新打开。新界面已有中英文；部分旧设置页仍是中文，下个版本补齐。

**升级须知：**
- 原有资料、题库、记录和模型继续兼容。
- “自动回答”不再是全局开关，改由会议类型和会中的“提词 / 只记录”决定。
- 新手引导改为第一次点“开始”时就地申请权限，引导本身仍可在设置里打开。
- 升级前请结束辅助会话，并保留一份手动备份。

**验证说明：** 本版本是一次大范围界面重写，在用户明确要求下推进合并与发行。真实会议场景的长时间试用、英文界面全面检查和纪要质量评测尚未完成，不能视为全部验收通过。Apple Silicon / macOS 14+ 为目标；发行包的构建和签名结果以资产校验记录为准；未提供 Developer ID 公证。
