# InterviewHacker v1.7.0

默认系统 OCR，可选 PaddleOCR-VL-1.6 Q8 本地识别，或让已有 Codex CLI 的 gpt-6-luna 代读原文件。Qwen3-Embedding-0.6B Q8 为资料增加本地语义检索，模型合计约 1.88 GB。

Office、Paddle、语义检索与 Codex 文件工具使用应用管理的运行包：下载约 186 MB，安装约 632 MB，无需手动安装 Python、pip 或 Homebrew。运行包是本 Release 的独立 tar.gz 资产，在应用“设置 → 文档模型”内安装。

资料保留完整 Markdown、表格／公式与真实定位；原件临时副本在处理后删除。模型可取消下载、校验修复和删除。向量缓存按工作区、资料版本、模型 revision 和切片版本隔离，实时回答等待语义查询不超过 500 ms。

六份固定样本的真实对照：三条路线均完成 6/6，关键数字系统 23/27、Paddle 27/27、Luna 27/27；结果只适用于这组样本。表格／公式、读取过程、原始输出与限制见[验证报告](https://github.com/OmnixSI/InterviewHacker/blob/main/docs/VALIDATION-v1.7.0.md)。

兼容目标 Apple Silicon / macOS 14+。本次实际测试为 M2 Pro 16 GB / macOS 26.5.2，未声称 macOS 14 真机验证。沿用本机既有签名约定；未配置 Developer ID 公证。本机私钥不会上传。

下载 DMG 拖入 Applications，或使用 ZIP。更新程序读取 update.json 与 SHA256SUMS.txt；发布前全部资产齐备并校验。模型、运行包和可重建索引不进入资料备份。
