## InterviewHacker v1.4.1

### 界面更顺手
- **设置改成左右布局**：和“场景”页一样，左边是分组，右边是设置内容。“基础”上的数字表示还有几项必需设置没完成。
- **切换页面不再闪烁**：助手 / 场景 / 记录 / 设置 之间切换是瞬间的，并且会记住每页的滚动位置。
- **按钮更大、更统一**：顶栏标签和开始 / 暂停 / 停止按钮加大，当前页高亮更明显；窗口较窄时标签只显示图标，右侧按钮不会被挤出窗口；场景编辑和会话记录里的分页改成胶囊标签。

### 自动更新更容易设置
- 保存的令牌无权访问仓库时，自动改用 GitHub CLI（`gh auth login`）的登录再试一次。
- 出错时说明原因，比如创建令牌时 Resource owner 应该选组织而不是个人账号。
- 新增“去 GitHub 创建令牌”按钮和填写步骤；授权有问题时，“GitHub 访问”会直接展开。

### 安装
已经装了 1.4.0 的话，在应用内更新即可。新安装请下载 `InterviewHacker-1.4.1-macOS-arm64.dmg`，拖进“应用程序”；应用未经公证，首次打开时到 系统设置 → 隐私与安全性 点“仍要打开”。需要 Apple Silicon 与 macOS 14+。
