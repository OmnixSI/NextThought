# Interview Hacker v2.1.1

本版本改进实时转写的底部显示，并让会议归档、资料夹和会前信息更容易浏览与操作。

## 实时记录

- 底部识别与翻译状态栏按实际高度为对话列表留出空间，滚动到底部时最后一条转写和译文可完整显示。
- 转写、翻译和部分识别内容更新时继续跟随最新内容；暂停自动跟随后仍可手动查看历史。

## 会议归档

- 所有会议按系列分组为行式列表；系列显示会议数量和最近时间，长名称可换行显示。
- 系列按最近匹配的会议排序，选定的排序规则应用于组内会议。
- 搜索范围、数量说明、空系列和筛选无结果状态保持一致，并提供清除条件或返回所有会议的入口。
- 删除全部会议记录的入口和确认说明明确指出会影响所有系列。
- 会议行和系列入口提供按钮语义、键盘焦点与选中反馈。

## 资料夹与会前准备

- 可折叠的背景信息显示填写状态和项目数量；资料启用、导入、分类移动和移除操作的文字与辅助功能说明更明确。
- 首页最近会议行有清晰的点击、焦点和选中反馈；准备页说明会议名称可选并可会后修改。
- 会议详情页标明模板和复制操作只影响纪要，不更改转写或会中提词。

## 升级

原有会议记录、纪要、资料、系列、模型、设置和本机权限继续兼容。需要 Apple Silicon 和 macOS 14 或更新版本；GitHub 构建与签名结果以本版本工作流为准。
