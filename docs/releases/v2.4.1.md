# NextThought v2.4.1

本版本加强会议归档的故障可见性、删除恢复、系列知识来源追踪，并为会中长转写布局增加可重复验收。

## 会议归档

- 归档读取失败会明确显示，不再伪装成空会议列表；存在读取问题、恢复队列或只读兼容数据时，会阻止破坏性删除。
- 保存回执、待写入数量、最后一次持久化时间和失败原因继续可见，写入失败可重试。
- 删除会议时先标记来源不可用，停止迟到摘要回写，再清理系列依赖内容并移除归档文件。磁盘删除失败时保留待重试状态。
- 文档任务在取消、失败和重启恢复时保持文件状态与任务收据一致；系列删除按事务日志恢复。

## 系列来源与备份

- 会议、经验和答法来源在备份合并中保留；已删除来源作为墓碑继续生效，不被旧备份复活。
- 接受的内容与人工修改历史不会因合并顺序或旧副本覆盖而丢失；相同来源不会重复计数。
- 系列简报只显示当前可用的来源，手动保留的内容明确标注来源已删除。

## 会中界面与发布

- 会中正文和控件使用系统文字样式；长部分转写增加时，输入框与主要操作保持原位。
- 新增 19 场景原生 SwiftUI/AppKit 验收矩阵、组件样板图、重叠状态预览和确定性几何断言。
- Release 工作流按生成清单验证正式资产名称和 SHA-256，并在发布前回读核对。

## 验证与边界

- `swift test --disable-sandbox`：480 项通过。
- release 构建通过。
- 合成矩阵生成 114 张截图，覆盖 19 种状态、浅色/深色、1200/960/900 pt 宽度；另有 24 张代表截图、组件样板图和证据弹出层截图。
- 几何检查将合成部分转写增长 203 pt，输入框与主要操作漂移均为 0 pt；取消后到达的合成回答结果未覆盖已保留的部分回答。
- 该验收集不包含真实音频、ASR、网络调用、归档写入或真实会议。macOS 大字号、原生键盘/鼠标焦点记录、VoiceOver、IME 和实体设备体验仍需按设备验收计划完成。

需要 Apple Silicon 和 macOS 14 或更新版本。
