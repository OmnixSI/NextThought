# NextThought v2.5.0

围绕组会和研究讨论，连接资料准备、个人笔记、证据核对和下一步行动。

## 更轻的导航与设置

- 工作区使用首页、所有记录、项目与课程三个顶栏入口，给资料和正文更多空间。
- 设置使用独立、可调整大小的窗口；打开、关闭或反复进入设置会保留工作区和编辑草稿。
- 六类任务目录整合原有全部配置；分类内直接切换分区，搜索仍可定位具体设置项。
- 通用页聚焦语言、外观和工作台；诊断与环境修复移到数据与隐私。表单使用原生菜单控件，统一字号、留白、选择状态和键盘焦点。

## 内容留存与资料准备

- 录制能力与可选的 AI 服务分开；准备页选择使用本场快照，不修改项目默认值。
- 支持独立个人笔记、重点和人工纪要版本，重整纪要保留人工修订；中断回答保留已显示片段。
- 搜索、复制、导出与纪要核对共用有效内容；支持个人笔记和重点检索。
- 大型文字 PDF 直接提取文字层，扫描页按需识别、保留检查点；缺组件显示可恢复的等待原因。
- 备份纳入个人内容和自定义模板；导入先预览新增、相同和冲突，冲突默认保留本机，并先建立恢复点。
- 复制项目使用独立资料归档，保留 v2.4.1 的来源完整性、持久化回执与删除恢复保护。

需要 Apple Silicon 和 macOS 14 或更新版本。PDF 的实际耗时取决于页数、扫描图像与识别方式；合成文字 PDF 的性能结果不能代表所有扫描文档。
