# InterviewHacker v2.0.1

v2.0.0 的修复版本，建议所有人更新。

**中文系统显示成英文的问题已修复。** v2.0.0 在中文系统上，首页、准备、会中和纪要的文字会显示成英文。原因是简体中文作为源语言没有打包自己的文字表，系统找不到时退回到了英文。现在中英两套文字表都会打包；“设置 → 基础 → 语言”选“跟随系统”时，中文系统显示中文，其他语言的系统显示英文。

**“立即记录”的快捷键改为 ⌘⇧N。** 原来的 ⌘⇧R 与全局“重新生成”快捷键冲突。

**其他：**
- 资料夹和技能设置里剩下的“场景”改成“系列”；“回答”设置的说明不再提已取消的“自动回答”。
- README 按 v2 界面重写，截图由 `scripts/capture-screenshots.sh` 从演示模式生成。

**升级须知：** 资料、题库、记录和模型不受影响。升级前请结束正在进行的会议。

**验证说明：** 构建前运行了全部单元测试；中英文界面用演示模式截图逐页检查过。真实会议场景的长时间试用和纪要质量评测仍未完成。未提供 Developer ID 公证。
