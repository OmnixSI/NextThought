# NextThought v3.0.0

开会前只做一个决定：这是什么场合。场景带上回答方式、纪要模板和会中提示，回答显示在摄像头正下方。

## 场景

- 面试重新回到场景列表，小组作业是新增的一项；和组会、汇报 / 答辩、客户沟通、工作会议、讲座 / 课程、小组讨论、通用并列。
- 每个场景同时决定会中模式、回答风格、纪要模板、问题敏感度、资料栏位、提词排版和教练重点；仍可在会中随时改。
- 首页只有一个开始框：给会议起名，选场景，点开始。需要先放资料时进入准备页。

## 提词岛

- 建议回答出现在摄像头正下方，从 MacBook 刘海处长出来，视线不用离开镜头。
- 只显示要点：结论加每一点的开头，随你已经说出口的内容往下走；也可切换为逐句显示。
- 鼠标不在上面时点击穿过它；鼠标停在上面才展开会议面板：立即回答、切换自动回答或只记录、暂停、结束、实时字幕和教练数据。
- 不在会议中时，鼠标停在刘海上可以选一个场景直接开始。
- 不想贴着摄像头时，可在设置里改回可移动的浮窗。

## 临场教练

- 会中提示语速、一次说了多久、你占了多少发言；各场景的标准不同，讲座不提示。
- 可选择留意眼神：用摄像头画面在本机提取面部特征点来判断是否看向镜头，画面不保存、不上传。

## 屏幕共享

macOS 15.4 起，窗口无法再让自己不出现在 ScreenCaptureKit 的屏幕捕获里。提词岛停在摄像头所在的屏幕；当 Zoom、Teams、腾讯会议、飞书、钉钉或 Webex 共享这块屏幕的整屏时，它会收回刘海。共享单个窗口或另一块屏幕时，提词岛不会进入画面。

## 界面

- 新的视觉：暖纸色、墨色和一个朱红强调色，每个场景一种低饱和矿物色。
- 导航放进窗口标题行；会中、准备、所有记录、资料夹和设置页按同一套样式重做。

## 开发

`scripts/dev/preview.sh` 可以在屏幕之外渲染演示页面，用于截图和检查界面，不显示窗口。
