# NextThought v3.0.0

开会前只做一个决定：这是什么场合。场景带上回答方式、纪要模板和会中提示，回答显示在摄像头正下方。

## 场景

- 面试重新回到场景列表，小组作业是新增的一项；和组会、汇报 / 答辩、客户沟通、工作会议、讲座 / 课程、小组讨论、通用并列。
- 每个场景同时决定会中模式、回答风格、纪要模板、问题敏感度、资料栏位、提词排版和教练重点；仍可在会中随时改。
- 每个场景有自己的提示、标题匹配和教练标准：标题里的“小组会”“项目会议”算工作会议而不是组会，“课程设计”算小组作业而不是课程，“Lecture 4”“第 3 讲”归入同一个系列。
- 汇报 / 答辩有了自己的纪要模板：一句话总结、听众 / 评委的提问（逐题记录你的回答和更好的答法）、没讲清楚或被质疑的地方、幻灯片 / 论文要改什么、答应的跟进和截止时间。组会的模板改名为“组会 / 研究讨论”。
- 首页只有一个开始框：给会议起名，选场景，点开始。需要先放资料时进入准备页。没起名就开始的会议，归入该场景下的“<场景> · 未命名”系列，不占用“继续上次”列表。
- 准备页可以选“只记录对方”：这一场不使用麦克风，只记录电脑里播放的声音，之后可以在准备页重新打开。

## 提词岛

- 建议回答出现在摄像头正下方，从 MacBook 刘海处长出来，视线不用离开镜头。
- 只显示要点：结论加每一点的开头，随你已经说出口的内容往下走；也可切换为逐句显示。
- 鼠标不在上面时点击穿过它；鼠标停在上面才展开会议面板：立即回答、切换自动回答或只记录、暂停、结束、实时字幕和教练数据。
- 不在会议中时，鼠标停在刘海上可以选一个场景直接开始。
- 不想贴着摄像头时，可在设置里改回可移动的浮窗。
- 岛不会压在会中窗口上：会中窗口在前台时，岛让到一边。
- 会议自动收尾的倒计时直接显示在岛和字幕条上，可以取消倒计时继续记录，也可以立即结束并整理纪要。
- 自动回答开着、回答服务却没有连接时，岛和会中页都会说明，不再安静地不回答。

## 临场教练

- 会中提示语速、一次说了多久、你占了多少发言；各场景的标准不同，讲座不提示。
- 可选择留意眼神：用摄像头画面在本机提取面部特征点来判断是否看向镜头，画面不保存、不上传。
- 会后的纪要标题下保存这一场的教练数据：发言占比、最长一次连续说了多久、看镜头的比例。没有数据的项不显示。

## 屏幕共享

macOS 15.4 起，窗口无法再让自己不出现在 ScreenCaptureKit 的屏幕捕获里。提词岛停在摄像头所在的屏幕；当 Zoom、Teams、腾讯会议、飞书、钉钉或 Webex 共享这块屏幕的整屏时，它会收回刘海。共享单个窗口或另一块屏幕时，提词岛不会进入画面。

## 设置

设置改成两层，不再是单独的窗口。

- **快速面板**：点标题行右上角的齿轮，弹出一个面板。上面三行状态：回答服务、声音、语音识别，需要处理的那一行直接带操作按钮；下面六项偏好：提词岛或浮窗、提词字号、临场教练、留意眼神、会后自动整理纪要、外观。底部有“全部设置…”和检查更新。
- **全部设置**：在主窗口里打开，分六页：场景、回答与资料、提词与教练、纪要、通用、高级。左上角的返回键（Esc）回到刚才的页面；会中打开设置不会丢失正在编辑的项目和会议草稿。搜索可以直达具体设置项。
- **场景页**：一张表，每个场景一行，设置会中模式（自动回答或只记录）、回答（简洁或详细）、纪要模板、提词（只看要点或逐句），行内有“恢复默认”。开始一场会时按这里的设置来，会中仍可随时切换。设置保存在每个场景自己的默认值里。
- **高级页**：声音与识别、回答服务、资料组件、纪要、提词、手机伴侣、更新、数据与维护，各自折叠，日常用不到。
- 权限、备份与恢复点、更新渠道都在通用和高级页里。

## 首次使用

首次启动的引导重写为四步：场景、声音、回答、提词与开始。

- 第一步选一个最常用的场景，可以看一段面试示例（不录音、不申请权限、不调用模型）。
- 第二步只在这里询问系统音频和麦克风权限，选线上或线下，选是否记录自己的声音；本机语音识别模型在这里下载，下载时显示进度，可以取消或重试。
- 第三步连接回答服务，可以跳过；不连接也能记录和转写。
- 第四步看提词岛的样子，然后开始第一场，或者先看看。
- 引导中途放下，首页会出现“继续完成设置”一行，写明还差什么，点一下回到上次停下的那一步，也可以不再提示。

## 会议不会悄悄丢失

- 会议进行中退出、更新或切换语言，会先询问；确认后结束这场会议，纪要在下次打开时自动整理。
- 会议结束时主窗口回到前面，不会停在别的窗口后面。
- 上次会议被意外中断，下次打开时首页说明，记录保存在所有记录里。
- 纪要需要回答服务而没有连接时，会直接说明，而不是显示一条无关的失败。
- 个人笔记、编辑过的纪要不会被覆盖：对改过的纪要重新整理，会先询问，生成的新版本和你改过的版本并存，可以查看并选用。纪要重新整理后，恢复点同步刷新。

## 界面

- 新的视觉：暖纸色、墨色和一个朱红强调色，每个场景一种低饱和矿物色。
- 导航放进窗口标题行；会中、准备、所有记录、资料夹和设置页按同一套样式重做。
- 标题行上的按钮和整行可点区域修复，不再需要点中很小的一块。
- 界面全部有英文版本；回答语言仍跟随问题。
