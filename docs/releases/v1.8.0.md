# InterviewHacker v1.8.0

所有设置重新梳理：默认只显示核心准备与日常操作，右上角统一“高级设置”开关展开复杂参数、技能、备份策略与维护工具。关闭开关保留已有配置；API 地址、密钥和模型等必填字段始终可见。

首次安装和功能版本升级展示五步引导：认识助手 → 准备语音 → 连接对话 → 资料可选 → 选会议窗口并开始。语音识别与对话回答是核心准备，OCR 和向量检索按需启用。未完成的引导保留进度，同一功能版本内的补丁不重复展示。

资料设置区分“已安装”“需要下载”“正在使用”和依赖未就绪，按功能一键准备完整组件，支持取消、复用与晚到选择保护。每种方案说明存储、内存、网络、账号额度和质量取舍。关闭向量后仍按关键词检索片段，不会自动将全部资料发送到上下文。

沿用 v1.7.0 的固定模型与文档运行包，已安装组件无需重新下载。系统识别与关键词查找无需额外文档模型；文档运行包仍是独立资产，不需要用户安装 Python、pip 或 Homebrew。

验证：143 项 Swift 测试、4 项 Python 文档测试、CodexTransport 回归，以及隔离 App 数据、设置/引导、签名、更新和 X-ASR 自检。23 个原生 UI 状态用于检查界面；截图使用模拟权限/模型状态，未用截图代替真实语音或 OCR 准确度测试。详情见[设置验证报告](https://github.com/OmnixSI/InterviewHacker/blob/v1.8.0/docs/VALIDATION-SETTINGS.md)。

Apple Silicon / macOS 14+ 为兼容目标；实际验证机器为 M2 Pro 16 GB / macOS 26.5.2，尚无 macOS 14 真机结果。沿用既有本机签名，未配置 Developer ID 公证，不上传本机私钥。

下载 DMG 拖入 Applications，或使用 ZIP。安装前请结束正在进行的辅助会话；更新保留本机资料与模型。更新程序会校验 SHA-256 和签名。
