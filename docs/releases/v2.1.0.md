# Interview Hacker v2.1.0

本版本整理了会议归档、资料夹和设置界面，并加入会议中的本机中英双向同声传译。

## 会议归档

- 所有会议页按系列分组，点进系列后查看其中的会议；顶部层级导航可以点击返回任意上级。
- 会议列表支持右键菜单，操作与纪要页的更多菜单一致。
- 新增会议详细信息面板，显示开始时间、时长、发言人、纪要状态、会议文件位置和占用空间。
- 顶栏侧边栏按钮固定显示在会议与资料夹栏目，用户可收起侧栏，将空间留给会议正文或系列表单。
- 中断的纪要整理任务会在下次启动后恢复，不重复处理已经完成的纪要。

## 会议中的中英同声传译

- 点击会中“同声传译”后，同时处理对方的系统音频和用户自己的麦克风语音。
- 自动判断每段中文或英文，并双向显示对应译文。
- 使用 macOS 本机 Translation 框架；无需另装大型翻译模型。译文与原转写分开保存。同声传译需要 macOS 15 或更新版本。

## 资料夹与设置

- 表单分区更简洁，现有资料、要求、技能、经验库、题库和复盘功能都保留。
- 卡片在宽窗口使用等高双列布局，在窄窗口改为铺满的单列布局。
- 提词建议区域改用与软件一致的中性灰色。
- 应用显示名称更新为 **Interview Hacker**。

## 升级

原有会议记录、纪要、资料、系列、模型与设置继续兼容。更新前请结束正在进行的会议。macOS 14 或更新版本，Apple Silicon。

本机版本使用已绑定的 Local Signing 身份构建，保持 `com.interviewhacker.app` 的 Bundle ID 与 designated requirement，以维持已授予的麦克风、录屏和系统音频权限。GitHub Release 的签名与公证状态以该版本工作流结果为准。
