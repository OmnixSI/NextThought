# NextThought v2.4.0

本版本把“开始记录 → 找回原话 → 核对纪要 → 导出成果 → 准备下一场”接成一条更可靠的路径。

## 记录和查找

- 已准备好的本机语音识别可以独立开始记录。回答服务、资料索引和翻译不再挡住会议开头。
- 历史内容搜索覆盖转写原文、人工校正、译文、问答和纪要，不再只搜最近一小部分会议。
- 搜索结果保留会议、内容类型、时间、稳定转写行 ID 和来源版本，可直接跳到命中的原话。
- 编辑结构化纪要后，旧的渲染摘要搜索命中会标为过期，避免看起来像当前内容。
- 最终译文会在归档结束前完成写入；搜索扫描遇到迟到译文不会反复重启或过早发布不完整结果。

## 会中和归档状态

- 用户上翻阅读或选择原话时，对应面板暂停跟随；“回到现场”恢复该面板的实时跟随。
- 归档公开待写入数、最后一次保存时间和失败原因；失败内容可重试，历史文件读取错误不会伪装成空会议。
- 手动编辑纪要只有在目标仍有效且归档写入确认后才显示保存成功；纪要重新生成时会暂缓手动编辑，避免覆盖正在生成的结果。系列材料筛选和异步加载的上一场转写会保留在已归档会议上下文中。
- 会后自动恢复点等待最终译文和归档写入完成；保存失败时不会生成不完整恢复点。
- 转写、校正、说话人和译文由共享投影提供给页面、搜索与导出。导出时可以明确选择校正版本或原始记录。

## 纪要依据和导出

- 纪要页新增“原话依据”面板。逐条显示匹配到的引文、仅关联时间、找不到引文或无原话定位；引文出现不等于结论已确认。
- 可以从依据跳回精确转写行，也可直接编辑对应纪要条目。只有时间点的模型结论仍会标记为待核对。
- 导出前可以预览所选文本版本和语言，支持 Markdown、Word（DOCX）、PDF、SRT 与 WebVTT。
- 字幕没有原始结束时间时会估算并在预览说明；来源版本变动后可能过期的译文会单独标记。

## 准备下一场

- 同一系列的准备页会显示本机生成的系列简报：最近会议、已确认经验和已确认答法。
- 简报条目可跳回来源会议；被删除或不存在的来源不会显示成可用链接。
- 待确认建议保持单独状态，不作为已确认知识带入；关闭系列知识后，简报和会议上下文都会尊重该设置。

## 知识保护

- 会后整理和阶段复盘先生成候选；接受、保留、替换或拒绝均有操作回执，重复提交不重复计数。
- 替换答法前保留上一版本及来源；手动编辑后的答案不会被错误标注为模型来源。

## 验证与边界

- `swift test --disable-sandbox`：446 项通过。
- `NEXTTHOUGHT_DATA_DIR=<scratch> NextThought --self-test session-export`：Markdown、可编辑 DOCX、34 页 PDF、SRT 和 WebVTT 生成与读取通过；表格单元格会换行，过宽表格改为标注行以避免超出页面。
- `NEXTTHOUGHT_DATA_DIR=<scratch> NextThought --self-test session-backup-drain`：会后恢复点包含最终译文。
- `NEXTTHOUGHT_DATA_DIR=<scratch> NextThought --self-test session-edit-receipts`：编辑回执只在内容持久化后成功，并拒绝过期目标及纪要重新生成期间的编辑。
- `NEXTTHOUGHT_DATA_DIR=<scratch> NextThought --self-test session-carry-context`：归档包含异步载入的上一场转写，同时排除被筛掉或关闭的资料。
- Codex transport、LegacyOffice、7 项文档规范化测试及伴侣 relay/browser/protocol 检查通过；iOS UI 构建未在本机验证。
- 本机未运行会中页的深浅色、窄屏、大字号和真实流式 16 态矩阵，也未作真实会议录音、麦克风/系统音频矩阵或长时真机流式评估；请按仓库验证计划完成设备实测。

需要 Apple Silicon 和 macOS 14 或更新版本。
