## InterviewHacker 0.2.0 beta 4

液态玻璃界面的修复版，基于 macOS 26 上自动截取的真实界面逐项调整：

- 浅色模式下下拉菜单、输入框占位文字发白看不清的问题已修复。
- 主按钮在提词器等非活跃窗口里也保持紫色，不再变灰。
- 内容滚到悬浮栏下方时柔和淡出，不再与底部输入栏重叠。
- 提词器去掉了浮在外面的红绿灯按钮，改为面板内的关闭按钮。

### 安装 / 更新

- 推荐：在仓库目录运行 `./scripts/install-latest.sh`（需要已登录的 GitHub CLI），不会弹“仍要打开”。
- 或下载 **`InterviewHacker-0.2.0-beta.4-macOS-arm64.dmg`** 拖进“应用程序”，首次打开到 **系统设置 → 隐私与安全性** 点 **“仍要打开”**。

如果还没有运行过 `./scripts/setup-release-signing.sh`，本版本仍是临时签名，升级后可能需要重新授权录屏与麦克风。
