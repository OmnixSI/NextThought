# Interview Hacker v2.3.0

本版本让软件更好点、设置更少，第一次使用时就把该准备的都准备好。

- **更好点**：按钮、图标和开关的可点击范围放大；开关整行可点；折叠标题整行可点。
- **设置更少**：简洁模式只留常用项，语音、回答服务、资料增强只显示状态和“重新设置”，少用的开关收进“高级设置”。
- **引导**：新增“你的声音”一步；资料一步自动查找本机已有的 OCR、版面和向量组件，一键启用。
- **区分说话人默认开启**，录入“我的声音”后自动认出你自己。
- **纪要格式随点随出**：纪要页顶部切换「纪要 | 提纲 | 鱼骨图 | 观点对照」，各格式并列保存，不再会后自动生成。

需要 Apple Silicon 和 macOS 14 或更新版本。
