## InterviewHacker 0.2.0 beta 1

会议、面试、网课的实时 AI 提词助手（原生 macOS，Apple Silicon）。这是第一个可以直接下载的版本。

### 下载与安装

1. 下载下方的 **`InterviewHacker-0.2.0-beta.1-macOS-arm64.dmg`**，打开后把 InterviewHacker 拖进“应用程序”。
2. 第一次打开会被 macOS 拦截（应用没有经过 Apple 公证）：打开 **系统设置 → 隐私与安全性**，在底部点 **“仍要打开”**。
   或在终端执行：`xattr -dr com.apple.quarantine /Applications/InterviewHacker.app`
3. 按提示允许 **屏幕与系统音频录制** 和 **麦克风**。

需要 M 系列芯片的 Mac、macOS 14 或更新版本。使用说明见 [README](https://github.com/ooooooomygosh/InterviewHacker#快速上手)。

### 这一版的重点

- ✍️ **流式回答**：常驻 Codex 服务或任意 OpenAI 兼容 API，逐字出现，显示首字耗时
- 🧠 **问题识别**：自动区分陈述、未说完、提问、请求解释、追问，少误触发；拿不准的句子一键回答
- ⚡ **更快的识别**：Whisper 说话中预览、更短的句末等待；可选云端流式识别（Soniox / OpenAI / Deepgram）
- 📄 **资料**：Word / PPT / Excel / 图片 / 扫描 PDF（OCR），预设与场景模板，会前预测问题
- 🪟 **提词器**：半透明、鼠标穿透、摄像头下方定位、一键隐藏、共享可见性测试
- 📱 **手机伴侣**：扫码在手机上看回答并遥控
- 🪄 **一键调整**：更简短、举例、STAR、英文版…

完整列表见 [CHANGELOG](https://github.com/ooooooomygosh/InterviewHacker/blob/main/CHANGELOG.md)。

### 注意

- 这是 **beta**：新功能通过了自动化测试和编译，但还没有完成真机人工验收。遇到问题欢迎提 Issue。
- 每次升级后如果录屏或麦克风权限失效，到“隐私与安全性”里重新勾选。
- 文件校验：`SHA256SUMS.txt`。
