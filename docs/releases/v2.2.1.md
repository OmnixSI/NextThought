# Interview Hacker v2.2.1

本版本改进公式显示。

- **公式显示**：回答、会后纪要和提词器里的 LaTeX 公式（`$…$`、`$$…$$`、`\(…\)`、`\[…\]`）显示为易读的公式：希腊字母和运算符用符号，`x^2` 显示为 x²，`\sum_{i=1}^n` 显示为 ∑ᵢ₌₁ⁿ，分数、根号、矩阵和分段函数写成一行或几行。金额里的 `$` 不会被当成公式，代码里的 `$` 保持原样。
- **回答提示词**：要求模型统一用 LaTeX 写公式。
- 复制和导出的 Markdown 仍是原始 LaTeX。

需要 Apple Silicon 和 macOS 14 或更新版本。
