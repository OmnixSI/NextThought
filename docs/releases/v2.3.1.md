# Interview Hacker v2.3.1

本版本重构设置层级，并修复已生成的鱼骨图显示为空白的问题。

- 设置改为左侧单层目录：声音、回答服务、纪要、资料、浮窗、快捷键、手机伴侣、数据、权限及更新可直接进入。
- 取消大分类与子页签的双重导航；不常用参数在当前页按用途展开，并分别记住状态。
- 资料读取和模型管理在同一页配置，移除“更改…”弹窗；搜索支持字幕、录屏等功能词。
- 工作台简洁/完整模式与设置可见性分离，原有配置保留。
- 修复鱼骨图等待宽度测量导致空白的问题；宽窗口显示图，窄窗口显示分类列表。已保存的内容无需重新生成。

验证：363 项单元测试通过；实际 SwiftUI 渲染检查在 720pt 与 420pt 宽度识别出所有分类；已验证设置导航、搜索和局部展开。签名沿用现有身份。

需要 Apple Silicon 和 macOS 14 或更新版本。
