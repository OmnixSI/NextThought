## InterviewHacker v1.3.0

### 亮点
- **场景分区 + 五种模式**：通用 / 面试 / 学术会议 / 商务会议 / 课程。每个场景（例如“字节后端二面”“ACL 口头报告”）单独保存信息、分类资料（简历、JD、公司、HR、八股面经；论文、PPT、讲稿…）、回答要求，一键切换。
- **复盘与自我迭代**：会后自动复盘（面试逐题评价、听众问题、会议决定与承诺），经验进入场景经验库，问到的问题和改进版回答进入题库，下次回答自动参考；可生成跨多次会话的阶段复盘。
- **会话记录**：完整转录、识别到的问题、提词和当时的资料自动保存，结束后生成摘要与完整问题清单。
- **识别更准**：默认改用 X-ASR 中英流式模型（带标点、中英混说）+ 整句精修二次识别；问题识别召回 70% → 100%、误触发 3 → 0（实测语料）；问句结尾约 0.6 秒开始回答，对方补充后半句自动改答。
- **抢话与回声**：麦克风里的扬声器回声自动识别并忽略；你在说话时等你说完再出回答。
- **新界面**：对话与回答并排、聊天式实时对话、顶栏常驻控制与音量表，更流畅。
- **自动更新与本机签名**：应用内检查、下载、校验并“重启安装”；“绑定本机签名”后更新不再需要重新授权录屏 / 麦克风。
- **数据不丢**：所有数据在本机一个文件夹；每日自动备份，更新和导入前也备份；一键导出 / 导入全部设置、场景和记录。

### 升级说明
- 首次打开会把原来的回答要求、背景说明和预设迁移为场景，原记录自动迁移。
- 本地识别需要下载新模型（约 270 MB，设置 → 识别 或助手页的“下载识别模型”）。
- 私有仓库的自动更新需要在 设置 → 更新 填只读访问令牌（或已 `gh auth login`）。
- 想以后更新不再重新授权：设置 → 常规 → 绑定本机签名（之后再授权一次即可）。

### 安装
下载 `InterviewHacker-1.3.0-macOS-arm64.dmg`，拖进“应用程序”。未公证，首次打开到 系统设置 → 隐私与安全性 点“仍要打开”。需要 Apple Silicon 与 macOS 14+。
