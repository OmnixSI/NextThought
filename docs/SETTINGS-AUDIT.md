# 设置控件盘点（v2.3 精简）

目标：第一次使用时把该准备的都准备好，之后基本不用调。设置的简洁模式只留“状态 + 一个修复入口”和少数真正会反复用的开关；其余收进“高级设置”，功能与已存的偏好键都不变。

处置：**保留** = 简洁模式可见；**高级** = 只在高级设置里可见（默认值不变）；**并入** = 合并到别的控件；**删除** = 界面上去掉（有安全默认值，或另有入口）。

## 分类

保持 5 个分类（≤ 6）：常规 / 会议与识别 / 回答与浮窗 / 纪要与资料 / 数据与更新。内部分组（`SettingsGroup`）、`@AppStorage("settingsGroup")` 和所有 `AdvancedOptions` / `@AppStorage` 键不变，旧偏好不丢。简洁模式下“技能”页签隐藏，其余页签不变。

## 自检要点（无编译器，人工核对）

- 被去掉的控件没有一个删除了它的状态变量或存储键；它们只是挪进 `AdvancedOptions` 或面板。
- 所有开关仍是标准 `Toggle(...)`，label 在左（点击区域由全局开关样式处理）。
