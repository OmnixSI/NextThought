## 二、CI 之后改的 6 处（未编译）

1. `MyVoice.swift`：录入中途离开页面时不再继续录音（`recordTake` 里加了两处 `guard isSettingUp`）。
2. `MyVoiceViews.swift`：麦克风被拒后，页面立即显示“打开系统设置”（多监听 `voice.message`）。
3. `OnboardingMaterials.swift`：去掉“最多等 10 秒”的限制，模型检查慢时扫描不再被悄悄跳过。
4. `LiveSessionView.swift`：菜单里的“快速模式”开关用系统样式（`.toggleStyle(.automatic)`）。
5. `SettingsView.swift`：字幕条设置移出“高级设置”（里面的“恢复默认位置”是字幕条被拖出屏幕后的唯一出路）。
6. `SettingsView.swift`：简洁模式的导入说明改为“…并一并恢复备份里的设置”，因为简洁模式下导入一直会覆盖设置。新增 1 条英文文案。

## 三、已知问题（没有修，按重要程度）

1. **引导资料步会自动扫描本机**（`OnboardingMaterials.swift`）：会遍历「下载」「文稿」和主目录，macOS 可能在首次运行时弹访问权限提示；也和 `LocalDocumentAssets.swift` 开头“启动时不做大范围扫描”的说法不一致。选择之一：只扫模型目录和 HuggingFace 缓存；或改成按钮触发。
2. **纪要生成完成后会闪一下“还没有整理过 · 开始整理”**：此时点击会再发一次付费模型调用。（`AppState+StructuredNotes.swift` 与 `StructuredNotesView.swift`）
3. **重新整理文字纪要的同时生成结构图，可能丢掉刚生成的结构图**：窗口很窄，概率低。（`AppState+Notes.swift`）
4. **结构图“重新生成”失败时界面没有任何提示**；没配置纪要模型时的提示也是“重试”，实际重试没用。
5. **简洁模式下资料页“更改…”窗口不含模型管理**：没有校验、修复、删除和 OCR 回退开关。组件损坏时要先打开“高级设置”。
6. 重新整理文字纪要后，页面可能停在你上次选的鱼骨图而不是“纪要”。

## 四、请在 Mac 上检查

**点击与外观**
- [ ] 设置里的开关：点文字也能切换、悬停高亮、空格键可切换、禁用状态正常、长文字换行正常。
- [ ] 菜单里的开关（实时窗口“快速模式”）显示正常。
- [ ] 折叠标题（`DisclosureGroup`）整行可点，展开动画和缩进正常。
- [ ] 实时窗口、提词器顶部图标行没有被撑挤（提词器七个图标约 252 pt，窗口最小 360 pt）。
- [ ] 转写行、状态行、洞察面板里的文字按钮变高后没有错位。
- [ ] 回答浮窗和字幕条没有套用新开关样式，确认它们没有开关所以不受影响。

**设置**
- [ ] 简洁模式每个分类页首屏看得完；“高级设置”打开后原来的项都还在。
- [ ] 常规页三行状态（语音 / 回答服务 / 资料增强）点“重新设置”能跳到对应位置。
- [ ] “重新打开新手引导”按钮可用。
- [ ] 识别页打开时自动刷新声音来源。

**引导（七步）**
- [ ] 第 4 步“你的声音”：首次麦克风弹窗、拒绝后的提示、从系统设置回来后状态更新、录入成功后“已录入”、“以后再说”。

## 五、发布步骤

1. 本地编译、自测通过。
2. 合并 `claude/ux-simplify` 到 `main`。**不要在最终发布提交里写 `[skip ci]`**，否则打 tag 后不会触发发布流程；上一次推送带了 `[skip ci]`，发布前请再提交一个不带它的提交。
3. 打 tag `v2.3.0` 并推送（`docs/releases/v2.3.0.md` 已存在，发布流程会读取它）。
4. 签名仍用 GitHub Secrets 里的发布身份（需 `MAC_RUNNER=github`）；该流程的签名步骤仍然没有真实跑过。
