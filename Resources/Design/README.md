# Companion icon

Original project artwork: waveform inside a conversation bubble. No external assets or Apple SF Symbols were copied. The source SVG uses a 128-unit grid, 6-unit rounded strokes and the Astra-reviewed purple #5146C8. Android adaptive foreground retains the central glyph; iOS uses an opaque square and delegates corner masking to the system. Web uses an inline data favicon, requiring no extra route. Regenerate the iOS 1024px image with `swift scripts/render-companion-icon.swift`.
