InterviewHacker uses the Sherpa-ONNX C API and ONNX Runtime for offline streaming speech recognition.

Sherpa-ONNX v1.13.8 is licensed under Apache License 2.0:
https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.8/LICENSE
The Sherpa-ONNX package links its static macOS XCFramework into the application executable.

ONNX Runtime v1.28.2 is licensed under the MIT License:
https://github.com/csukuangfj/onnxruntime-libs/tree/v1.28.2

The default X-ASR zh-en models (https://github.com/Gilgamesh-J/X-ASR, Apache License 2.0)
are downloaded separately from the sherpa-onnx "asr-models" release and are not included
in the application bundle. Archive SHA-256 values:

The application embeds a SentencePiece vocabulary (piece and score per line) derived from the
X-ASR bpe.model, used for recognition hotwords.

The legacy bilingual streaming Zipformer model is downloaded separately from:
https://huggingface.co/csukuangfj/sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20/tree/98590b7ed6443e77b714204da2757d75e1a642f4
It is licensed under Apache License 2.0. The model is not included in the application bundle.
